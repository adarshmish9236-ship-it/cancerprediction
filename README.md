## 🔬 Platform Vision & Capabilities

**CANCERWISE AI** bridges foundational data mining, advanced supervised machine learning, deep learning, and state-of-the-art Explainable AI (XAI) to analyze breast cancer fine-needle aspirate (FNA) cytology and multi-modal oncology data.

### Core Innovations & Modules:
1. **Primary Dataset Engine:** Ingests the Wisconsin Diagnostic Breast Cancer (WDBC) cohort (569 FNA biopsies, 32 morphometric features), ensuring clinical provenance, de-identification, and data contract validation.
2. **Advanced Data Wrangling Studio:** Imputation benchmarking (KNN, MICE, median), duplicate audit (cosinine similarity protection), non-destructive quantile winsorization, and immutable JSONL transformation audit trails.
3. **Exploratory Data Mining & Hypothesis Testing:** Shapiro-Wilk normality testing, Levene homoscedasticity, Benjamini-Hochberg False Discovery Rate (FDR) adjustments, Cohen's $d$ effect sizes, and mutual information ranking.
4. **Feature Engineering & Selection Laboratory:** Automated derivation of biomedical morphometric descriptors (circularity, nuclear border irregularity, worst-to-mean expansion ratios) paired with cross-validated Borda consensus feature ranking.
5. **Multi-Paradigm Machine Learning:** 16 supervised classifiers across 7 distinct paradigms (Linear, Decision Trees, Ensembles, Boosting, SVM/Kernels, Instance-based, and PyTorch Neural Networks) with in-fold SMOTE resampling to eliminate data leakage.
6. **Advanced Data Mining Paradigms:** Semi-supervised label propagation under low-annotation regimes, PyTorch multitask learning, multiclass subtype prediction, continuous biomarker regression, and Mercer kernel Hilbert space mapping.
7. **Large-Scale Learning & Optimization:** High-throughput Polars/PyArrow streaming pipelines, automatic float64-to-float32 memory downcasting (saving ~50% RAM), and out-of-core progressive SGD learning.
8. **Explainable AI & Clinical Validation:** Dual-framework interpretability via Tree/Linear SHAP and LIME tabular rules, Platt/Isotonic probability calibration, 95% bootstrap confidence intervals, and automated PDF/HTML research report generation.
9. **FastAPI Microservices Backend:** 17 decoupled services, Pydantic v2 schemas, asynchronous job manager (`JobManager` threadpool), RFC-compliant centralized error handling, and secure file uploads.
10. **Modern Scientific Frontend:** 14-page Streamlit portal built with scientific dark/light themes, live system telemetry, interactive Plotly visualizations, and dual-mode REST/local API bridges.

## 🚀 Quickstart Guide

### Prerequisites
- Python 3.11, 3.12, or 3.14
- Git (recommended)
- Docker & Docker Compose (optional, for containerized deployment)

### 1. Local Installation

```powershell
# Clone the repository
git clone https://github.com/cancerwise-ai/cancerwise-ai.git
cd cancerwise-ai

# Create virtual environment
python -m venv venv
# Windows:
.\venv\Scripts\activate
# Linux/macOS:
source venv/bin/activate

# Install dependencies
pip install --upgrade pip setuptools wheel
pip install -r requirements.txt
```

### 2. Run Pre-Flight Diagnostics

Validate host configuration, hardware telemetry, dependencies, and socket availability:

```powershell
python scripts/preflight_check.py
```

### 3. Launch the Application

**Option A: 1-Click Universal Launch**
- **Windows:** Run `scripts/run_all.bat`
- **Linux/macOS:** Run `bash scripts/run_all.sh`

**Option B: Independent Services**
```powershell
# Terminal 1: FastAPI Backend
python -m uvicorn backend.main:app --host 0.0.0.0 --port 8000 --reload

# Terminal 2: Streamlit Scientific Frontend
streamlit run frontend/app.py --server.port 8501 --server.address 0.0.0.0
```

- **Frontend Portal:** [http://localhost:8501](http://localhost:8501)
- **Interactive OpenAPI Documentation:** [http://localhost:8000/docs](http://localhost:8000/docs)
- **ReDoc API Reference:** [http://localhost:8000/redoc](http://localhost:8000/redoc)

## 🐳 Docker Deployment

Deploy the complete multi-service architecture using Docker Compose:

```bash
# Build and run in detached mode
docker compose up --build -d

# Check service health and logs
docker compose ps
docker compose logs -f

# Stop containers
docker compose down
```

For live-reload development inside Docker:
```bash
docker compose -f docker-compose.yml -f docker-compose.dev.yml up
```
